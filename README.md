# Floquet-virtual-state-metrology-dce

Public deposit for the PRX Quantum manuscript on dynamical-Casimir
virtual-state metrology and the cavity-loss barrier.

Can ultrastrong-coupling circuit-QED metrology keep its dynamical-Casimir
QFI gains once the cavity leaks? No: at the physical coplanar-waveguide
linewidth (κ/2π ≈ 248 MHz) the single-qubit DCE QFI falls below 1 % of its
pure-state value, and the truncated-basis Dicke+DCE protocol retains only a
truncation-dependent ~7–16 % range. The idealized pure-state peak
(×170903 at η = 0.150) is a coherent Cramér–Rao upper bound the protocol
cannot reach on a lossy platform.
