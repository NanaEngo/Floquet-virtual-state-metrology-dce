`scripts/dce_interrogation_entropy.py` and stored in

the package and is not recreated; bibliography checking is run locally before submission.
Supporting data and code are available upon reasonable
request to the corresponding author; this package does not include a repository link.

```bash

export FORCE_SOURCE_DATE=1

# from this directory
pdflatex -interaction=nonstopmode 01_track_B_metrology_main.tex
bibtex   01_track_B_metrology_main
pdflatex -interaction=nonstopmode 01_track_B_metrology_main.tex

pdflatex -interaction=nonstopmode 02_track_B_metrology_SI.tex
bibtex   02_track_B_metrology_SI
pdflatex -interaction=nonstopmode 02_track_B_metrology_SI.tex

pdflatex -interaction=nonstopmode 02_track_B_metrology_SI.tex
pdflatex -interaction=nonstopmode 01_track_B_metrology_main.tex
```

The main and SI cross-reference each other through `xr`/`externaldocument` with the
numbered basenames above, so a fresh build must end with the SI resolved first and the
main rebuilt last (main → SI → SI → main, as listed). Compiling the main document last
is what resolves the `SI-sec` cross-references; building the SI after the main leaves
`??` references in the main PDF. The active root contains only the current PRX sources and support files;
archived audits and legacy cover-letter outputs are excluded from the submission set. The manuscript and SI use the `prx` REVTeX option; venue-specific
submission metadata must still be checked in the APS system.

## Loss-adjusted Dicke+DCE study — authoritative data (2026-09-02)

The **validated loss-adjusted Dicke+DCE run is the authoritative source for the reduced-basis mixed-state calculation** for every
mixed-state cavity-loss number quoted in the main text, SI (`sec:si_dicke_loss`,
`tab:si_dicke_loss`), data analysis report (§8), and cover letter. The single-qubit loss sweep has a separate sampled-threshold interpretation documented below. It supersedes the
earlier default-tolerance `dicke_dce_loss_adjusted.json` values (which were produced by
unconverged integration — failed numerical physicality checks, ~15% retention at
$\kappa/\omega_c=10^{-2}$, late-mean 0 — and must not be cited).

- **Canonical artifact:** `data/dicke_dce_loss_adjusted.json` (N_CAV=6 row: peak QFI
  2961.9 / 2927.4 / 2827.5 / 1817.6 / 474.3 at $\kappa/\omega_c = 0$, $10^{-4}$,
  $10^{-3}$, $10^{-2}$, $4.1\times10^{-2}$; retention 100 / 98.8 / 95.5 / 61.4 /
  16.0 %). A 20-point checkpoint matrix over $N_{\text{cav}}=6$–12 was run as SLURM
  array jobs 15744/15764/15784 with adaptive `atol=rtol=1e-10` and a `-1e-4` numerical eigenvalue
  acceptance floor; all 20 points pass the trace/Hermiticity/eigenvalue acceptance checks (worst min eigenvalue $-1.34\times10^{-5}$ against the $-1e-4$ floor). This is not a proof of exact positivity.
- **Raw evidence:** the per-point results are merged into the canonical
  artifact above (the checkpoint JSONs under
  `data/_dicke_loss_checkpoints/` were pruned after merging, and the
  per-job `slurm-15744/15764/15784_*.out` logs were pruned as excluded
  provenance). The task driver
  `dicke_dce_loss_adjusted_slurm.py` and the acceptance gate
  `validate_dicke_loss_checkpoints.py` were restored on 2026-09-03 as
  bytecode-identical reconstructions of the originals that ran the matrix
  (verified by recursive `compile()`/`dis` comparison against the preserved
  `.pyc` files); both are runnable from source.
- **Truncation caveat (required reading):** the absolute peak and the retention are
  *not* truncation-converged — peak QFI grows 2962 → 4833 over
  $N_{\text{cav}}=6$–12, and physical-point ($\kappa/\omega_c=4.1\times10^{-2}$)
  retention falls 16.0 % → 6.6 %. All quoted physical-point values are therefore a
  reduced-model range (~7–16 %), not a converged number; no Dicke-specific platform
  threshold is claimed. See the SI loss section and the JSON `caveat`/`validation`
  fields for the full statement.
- **Validation status:** the JSON
  `validation` block (numerical physicality gate PASS 20/20, monotonicity PASS at N_CAV=6/12, 5.0 %
  bump at N_CAV=10 flagged) passes; exact positivity is not claimed. `Track_B_data_analysis_report.md` §8 records the
  matrix and the correction history. The bibliography-checker output is run locally before submission and is not part of the package.

## Floquet-stability screening — finite-window result

Work Package A is implemented by `scripts/floquet_stability.py`. The Tier 1 artifact
contains 108 deterministic parameter rows with two cavity truncations and 40 drive
periods; the selected Tier 2 artifact extends five rows to 80 periods and two larger
truncations. The output labels rows as `growth_at_boundary` or `bounded_in_screen`.
These labels are finite-window diagnostics. The selected low-loss/resonant rows retain
boundary growth, so the package does not claim that two-level saturation is a passive
Floquet stabilizer or that it prevents parametric divergence.

## Multiparameter QFI and representation consistency

Work Package B is generated by `scripts/multiparameter_gauge_qfi.py` and stored in
`data/multiparameter_gauge_qfi.json`. The artifact contains 18 static/driven rows with
finite-difference QFI tensors, nuisance-parameter projections, conditioning diagnostics,
and step-refinement results. All rows are model-specific and use normalized parameters.
The controlled similarity check transforms the Hamiltonian, state, control interaction,
and observables together; it is a representation-consistency test, not a proof of
arbitrary physical gauge invariance or phase-noise protection. The data-analysis report
records the numerical results and limitations before any manuscript interpretation.

## Output-field homodyne CFI

Work Package C is generated by `scripts/homodyne_cfi.py` and stored in
`data/homodyne_cfi.json`. It uses a declared input--output convention, monitored
external-loss fraction, flat temporal mode, QuTiP quantum-regression correlations,
and a Gaussian moment-based homodyne CFI. The 24 resumable parameter groups yield
2,304 rows across LO phase, detector efficiency, temporal-mode resolution, window,
loss split, and cavity truncation. The best valid ratios are 4.55% for the static
protocol and 60.3% for the driven protocol; the historical 92.4% and 88.1% values
are not reproduced. This is a finite-model Gaussian readout screen, not exact
non-Gaussian field CFI or an experimental QFI-saturation result.

## Finite-temperature retention screen (Work Package D)

`scripts/thermal_competition.py` and `data/thermal_competition.json` implement the
finite-temperature Lindblad screen over $T\in[10,200]$ mK and $\omega_c/2\pi\in[5,8]$
GHz with explicit Bose--Einstein cavity occupations and separate qubit thermal rows.
With a predeclared 80% peak-QFI-retention criterion, 12 of 17 reference families reach
a sampled crossover within 200 mK; the canonical driven row crosses at 100 mK. The
historical $n_{\rm th}\approx10^{-4}$ at 20 mK and the fourfold-reduction hypothesis
are not reproduced by the explicit-frequency occupations and are not manuscript claims.

## Multilevel-emitter leakage screen (Work Package E)

`scripts/multilevel_emitters.py` and `data/multilevel_emitters.json` evaluate
transmon-like, flux-qubit-like, and fluxonium-like effective spectra over $d_e=2$--$5$
levels. No driven $d_e\ge3$ row meets the declared 1% maximum-leakage adequacy
criterion (window-maximum leakage 3%--82% across models and drive amplitudes). The
models are declared effective spectra; no two-level driven-row validity guarantee or
platform choice is claimed.

## Extended HEOM/Lindblad agreement screen (Work Package F)

`scripts/heom_extended_validation.py` and `data/heom_extended_validation.json` extend
the local Spin--Boson cross-check with hierarchy-depth ($L=2$--$5$), temperature,
coupling, cutoff, and time-window sweeps plus two driven rows at the DCE frequency
ratio. Fifteen of 18 rows pass the per-row physicality gate and are used for agreement
claims; three rows are preserved as inconclusive under a documented QuTiP hierarchy
positivity limitation. The hierarchy converges at $L=2$; driven DCE-ratio rows agree
with the Lindblad working model at the $\sim1\%$ QFI level.

## Larger-$N$ finite-size and resource screen (Work Package G)

`scripts/finite_size_resource_scaling.py` and `data/finite_size_resource_scaling.json`
evaluate the exact static Dicke ground-state QFI over $N=4$--$64$ with two cavity
truncations per size bracket (all truncation-converged) and canonical driven
Dicke+DCE rows with declared pump/emitted-photon proxies. The historical anchor
$N=32\to228.6$ and the $\alpha\approx2.20\pm0.04$ fit over $N\in[6,18]$ are
reproduced; growth bends sublinear beyond $N\approx21$ with no plateau reached up to
$N=64$. Fits are descriptive; no thermodynamic, super-Heisenberg, or global-bound
claim is made, and the resource comparison is partial.

## Static QFI-versus-coupling sweeps (figure panel data)

`scripts/dicke_eta_sweeps.py` and `data/dicke_eta_sweeps.json` evaluate the exact
static Dicke ground-state QFI versus coupling at $N=4,8,16,32$ (production-quality
$n_{\max}=35$, $n_{\text{eig}}=30$, $\omega_q/\omega_c=1.005$), reusing the finite-size
producer's physics core. Each curve is anchored at $\eta=1.15$ against the finite-size
grid (maximum relative deviation $2.5\times10^{-7}$). The sampled maximum shifts with
$N$ ($\approx1.40$ at $N=4$, $\approx1.15$ at $N=16$, $\approx1.10$ at $N=32$), so the
tabulated $\eta=1.15$ operating point is a fixed reference, not the optimum for every
$N$. `scripts/regenerate_dicke_scaling_figure.py` rebuilds the two-panel main-text
figure `figures/figB_dicke_scaling.pdf` from these two canonical artifacts
(byte-deterministic under `SOURCE_DATE_EPOCH`).
